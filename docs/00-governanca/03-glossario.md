# Glossário

**ID:** DOC-GOV-003  
**Fonte canônica para:** termos de produto e engenharia

| Termo | Definição |
|---|---|
| Agendamento | Reserva de um período para um cliente, profissional e um ou mais serviços. |
| Atendimento | Execução operacional resultante de um agendamento ou encaixe. |
| Barbearia | Organização cliente do Varthex Barber; também chamada de tenant. |
| Bloqueio | Exceção que remove disponibilidade de um profissional ou unidade. |
| Buffer | Intervalo adicional antes ou depois de um serviço. |
| Caixa | Período financeiro aberto por uma unidade para registrar recebimentos e ajustes. |
| Cliente | Pessoa atendida pela barbearia; pode ou não possuir login. |
| Comissão | Valor devido ao profissional conforme regra congelada no momento do atendimento. |
| Conciliação | Comparação entre registros internos e informações do meio de pagamento. |
| Consentimento | Manifestação ou base registrada para uma finalidade de tratamento de dados. |
| CRM | Recursos de segmentação, comunicação e retenção de clientes. |
| Encaixe | Atendimento incluído manualmente em uma disponibilidade permitida. |
| Feature flag | Controle que libera uma funcionalidade para planos, tenants ou grupos específicos. |
| Fila de espera | Lista de clientes interessados em uma vaga compatível. |
| Grupo de recebimento | Conjunto atômico de lançamentos usados para dividir um pagamento entre meios. |
| Idempotência | Propriedade que impede uma mesma solicitação repetida de produzir duplicidade. |
| Instância recorrente | Agendamento individual gerado a partir de uma série. |
| Multi-tenant | Arquitetura na qual várias barbearias usam a plataforma com dados isolados. |
| No-show | Falta do cliente sem conclusão do atendimento. |
| Plano do cliente | Pacote, mensalidade ou benefício vendido pela barbearia ao cliente final. |
| Plano SaaS | Assinatura que a barbearia paga à Varthex. |
| Profissional | Usuário apto a executar serviços; no MVP corresponde ao barbeiro. |
| RPO | Perda máxima de dados tolerável, medida no tempo desde o último ponto recuperável. |
| RTO | Tempo máximo planejado para restaurar o serviço. |
| Série recorrente | Regra que origina várias instâncias de agendamento. |
| Sinal | Valor antecipado exigido para manter um agendamento até o prazo definido. |
| SLI | Indicador medido de confiabilidade, como latência ou disponibilidade. |
| SLO | Meta interna definida para um SLI. |
| Super Admin | Operador autorizado da plataforma Varthex, não da barbearia. |
| Tenant | Identificador lógico da barbearia proprietária dos dados. |
| Unidade | Local físico de atendimento pertencente a uma barbearia. |
| Usuário | Identidade autenticável vinculada a uma pessoa e a um ou mais papéis. |
| Webhook | Chamada HTTP enviada por um fornecedor para comunicar um evento. |
| White-label | Personalização ampliada da solução para outra marca; somente release final se aprovada. |
